What Tidy does

Tidy removes URL parameters using built-in and custom rules. Optional features include short-URL expansion, History and convenience automation. You control the rules and available settings.

A cleaned URL can still identify you, contain sensitive information or lead to an unsafe website. Rules cannot recognise every tracking method, and removing a parameter can change a URL's behaviour. Review the result before using or sharing it, particularly for sign-in, payment, invitation or one-time URLs. Expanding a URL makes a network request and can activate a one-time URL.
